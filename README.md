# 词序

一个免安装、可离线使用的英语单词练习工具。

## 使用

直接用浏览器打开 `index.html` 即可。词库和练习记录会自动保存在当前浏览器中。

## 在手机上使用

让电脑和手机连接到同一个 Wi-Fi，然后在电脑上运行：

```powershell
.\start-mobile.ps1
```

终端会显示类似 `http://192.168.3.24:4173` 的地址。用手机浏览器打开该地址，即可在手机上练习。

在手机浏览器菜单中选择“添加到主屏幕”，之后就能像普通应用一样从桌面进入。使用期间需要保持电脑上的服务窗口开启。

这种方式下，手机上的词库和学习记录保存在手机浏览器中，不会自动同步到电脑。

在局域网版本中，导入窗口还支持从手机选择单词照片，调用电脑上的 Windows OCR 自动识别并整理成词库格式。照片只在电脑本机处理，不会上传到第三方服务。

## 云端词表同步

应用启动时会读取 `curated-words.txt` 的版本。词表内容变化后，新设备会自动使用云端词表，已有设备会合并新词并保留本机练习进度。

## 导入格式

每行一个单词，使用竖线分隔：

```text
abandon | 放弃；抛弃 | əˈbændən | Never abandon your goals.
benefit | 益处；使受益 | ˈbenɪfɪt | Regular practice will benefit you.
```

前两项为必填，音标和例句可以省略。也支持从 `.txt`、`.csv` 或 `.tsv` 文件导入。

## 已包含

- 混合随机、英译中、中译英、拼写题
- 题目顺序和选项顺序随机打乱
- 选择题答题后显示每个选项对应的英文或中文
- 薄弱词优先、错题重练
- 单词朗读、练习统计、本地自动保存
- 单个单词管理、批量导入和导出
